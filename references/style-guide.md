# 通用蜡笔画风格指南

生成前读取模块一、模块五，以及画面实际涉及的题材模块；混合场景组合使用。检查时依照同一组模块核对。主体不存在时，其条件检查项标为“不适用”，不得因此补造内容。

以下数字是便于组织提示词的美术默认范围，属于启发式视觉目标，未经效果测试标定，不是工具参数或精确检测阈值。以画面短边长度 S 作为相对尺度；示例换算按 S＝1024 像素。没有量化测量时，只描述观察到的视觉差异，不声称达到了某个精确百分比。用户指定的美术调整优先，主体可辨性和源图结构约束始终参与权衡。

## 一、全局材质笔触规范

### 笔触、纸张与轮廓

- **默认风格基准**：细腻轻彩蜡笔，兼容细线稿；薄而多层的色料落在白纸齿纹上，近看有颗粒，整体看仍有连续色面。粗犷表现档只在用户要求时启用。
- **主色块笔触宽度**：细腻档约 0.4%–1.2% S（约 4–12 像素），多次轻叠；粗犷档约 0.8%–2.5% S。天空等连续区域可用更宽的轻擦，不切碎渐变。
- **细节排线宽度**：细腻档约 0.1%–0.3% S（约 1–3 像素），保持轻细；仅用于眼睛、花纹、枝干和器物边缘，不在脸上或天空铺满粗斜线。
- **轮廓粗细**：通常约 0.1%–0.25% S，主要由源图线条决定，适度自然断续；粗犷档可增加。保持漫画眼睑、发梢、建筑边缘的精细关系，不用又黑又粗的封闭描边套全图。
- **色层**：以 2–4 组明暗关系为骨架，每组内可多次低压力薄涂；层间轻微交叠，不是 2–4 块硬边贴纸。浅色保留通透感，深色保持整体体积。
- **露纸量**：细腻档已涂深色区域通常仅约 2%–6% 的细小露纸；浅色因轻压可更多。粗犷档可增至约 5%–12%。不把暗衣刮成大条白线或把高光画成缺损斑块。
- **颗粒尺度**：细腻档以约 0.05%–0.15% S 的细小断点为主；纸齿低对比、尺度统一，强弱随色料覆盖变化。粗犷档可增至约 0.1%–0.3% S。白纸可有极轻明度起伏，避免彩色噪点、深脏污和全图黄纸罩染。
- **笔触方向**：跟随体积和材质走向；发丝、毛发、羽毛及叶脉随形，水面偏横向，墙体依平面排布，不用同一种斜线覆盖所有区域。

### 色彩约束

- **先选模式**：彩色源图默认保色；明确要求黑白则严格灰度；未指定保黑白的线稿默认允许低饱和艺术补色；有效果参考时，以其已获允许的主体配色为依据。保色规则不能覆盖用户明确要求的上色。
- **保色模式**：保留源图色相家族和饱和度等级，不整体套滤镜。作为提示词目标，主要色块的 HSV 饱和度相对源图尽量不偏离超过约 10 个百分点；不能因此抹掉源图已有的鲜艳区域。
- 原图低饱和时，使用同样克制的灰彩；原图高饱和时，保留其鲜艳重点。不得为“蜡笔感”额外添加荧光色、棕黄纸色或全图暖色罩染。
- **艺术补色模式**：保持原来的亮部、暗部和大色块面积，按“主体→部件→材质”分配协调的颜色，通常以 3–5 个主/辅色家族组织，但不限制细节色的数量。主色、暗部色、小道具色各司其职，不能把整个人物套同一层淡色。颜色属于新创作；不要将所有白发都规定为金发，或把所有深衣都规定为蓝色。无参考时采用克制的自然色关系，不擅自改有色照片中的既有颜色。
- **参考配色模式**：先提取“浅色主体偏暖、深色主体偏冷、少量玫粉点缀”等关系，再对应源图区域；题材不同时只迁移层次、柔和度与冷暖组织，不复制参考中的人物或物品。
- **本次人物示例的可用色锚**：用户提供的 Muse 效果图表现为浅奶金头发、极淡暖肤色、低饱和玫粉腮红/鼻尖、冷蓝黑衣物，以及少量赭金小配件；这些只适用于该人物示例。可用近似色锚组织提示词：发色 #F2EBC5、肤色 #F6EFDF、腮红 #D79DA5、深衣 #152333、纸白 #FCFCFA；它们不是固定像素目标或通用色板，纸面总体须看起来中性白。
- **严格黑白模式**：所有区域包含腮红均为灰度，不额外添加任何彩色点缀。

### 按部件与材质配色

生成前列出实际可辨区域的局部色彩计划。参照下列关系，不把示例颜色当作所有源图的规定色：

| 区域 | 配色组织 | 应保留的差别 |
| --- | --- | --- |
| 头发 | 底色、发束暗部、受光留白 | 浅发也有薄层色料，不是空白剪影；与皮肤颜色不同 |
| 面部 | 极淡肤色、面颊玫粉、鼻尖较集中暖色、唇部轻暖色 | 腮红中心与边缘有轻重，鼻尖与面颊不成为同一大块粉色 |
| 衣服 | 衣料固有色、褶皱暗部、边缘反光 | 深衣可有蓝黑/蓝灰层次，不仅是中性黑加白噪点 |
| 服饰细节 | 原有衣领、镶边、线迹、纽扣/金属件分别处理 | 白领冷灰白与暖金扣子可区分；无扣子不凭空新增 |
| 小道具 | 依据用户辨认或清楚可见的材质分部位配色 | 本次已由用户指明的香烟可区分白纸、淡赭滤嘴、可见烟灰的灰色；不新增烟雾或火光 |
| 其他题材 | 天空/植被/地面、动物毛色/鼻爪、器物本体/配件/反射分别处理 | 迁移的是分区配色的方法，不把人像示例颜色套给其他题材 |

原图无法确认某个细节是什么时，保留其形状，以局部冷暖或材质色差表达，不编造具体零件。深色细节可以含颜色而仍保持原来的明度，不为上色把所有暗部提亮。

### 检查清单

- [ ] 主要区域能看见蜡笔断续笔触、露纸与颗粒，整体仍可辨识。
- [ ] 没有退化成“照片加噪点”、光滑矢量填色或水彩晕染。
- [ ] 色块仍服从源图轮廓、光照和主色分布，未为了肌理改动结构。
- [ ] 相对于参考的线宽、颗粒尺度、叠色方式和暗部完整性接近；没有只把黑白线稿粗化后声称完成风格匹配。
- [ ] 补色模式下，不同部件与材质有适当对应的颜色；小道具、服饰细节和浅色区域没有被整体灰度化或染成同一种颜色。

## 二、人像面部与服饰规范

- 保留头身比例、头部朝向、五官相对位置、表情倾向、可见配饰及人物数量。多人分别保留身份线索，不合并、换脸或自动添加人物。
- **简化强度**：漫画/线稿保留原有眼形、眼睑、瞳孔位置、发丝走向和表情；以笔触替换媒介，不强制变成圆点眼。真人照片适度概括五官，用户要求稚拙风时再加大简化。不得新增睫毛、眉毛或其他原图不存在的五官。
- **腮红**：彩色模式中，使用低饱和玫粉，多层轻擦，通常可展开至可见脸宽的约 20%–35%，中心略实、外缘渐疏，透出肤色与纸齿。保留眼鼻嘴的间隙，不形成独立的高亮锯齿涂鸦；只处理真实可见的脸面区域，侧脸不补造另一侧脸。参考中有鼻尖或唇部轻暖色时可对应迁移；不要机械扩散至整脸或背景。
- 头发和衣物按原轮廓铺色；浅发可见柔和色层而非大片未涂白纸，暗衣用密实冷/暖深色叠层，保持原来的黑白明暗重量。保留衣领、帽子、袖口等高辨识结构，不另换服装。
- 远处小人、背影及遮挡脸不补造眼鼻嘴；面部简化要求仅对实际可辨的脸执行。

### 检查清单

- [ ] 人物数量、姿势、发型、服装与可辨身份特征仍对应源图。
- [ ] 五官保留身份与表情，简化强度符合源图与参考；腮红柔和融入肤色，未遮掉结构，未变成孤立贴纸块；粗眉有来源依据。
- [ ] 不可见五官没有补画；无人物时整组人像检查跳过。

## 三、风景与建筑表现规范

- 锁定地平线、消失方向、山脊、水岸、道路、楼体外轮廓与前中远景遮挡。可以简化小叶片和重复砖缝，不删除主干、楼体或改变地形。
- **风景笔触密度**：以有色区域内明显排线与颗粒的疏密作视觉目标：前景约 55%–75%、中景约 35%–55%、远景约 15%–30%。不作为像素覆盖率验收；源图远景本来清晰或高对比时先保留源图关系。
- 前景可使用短而密的交叠蜡笔线；中景合并成植物群、墙面或山体色块；远景采用较稀疏、低对比的轻擦。源图已有的雾感和空气透视保留，不凭空加雾。
- 天空、云和水面以较宽笔触表达：云保留轮廓与亮暗组团，水面保留反射的大形和主要水平走向，山石保留明暗面。避免逐片叶、逐块砖的照片级复刻。
- 建筑轮廓可轻微手绘化，仍保持直立面、屋顶、门窗组和透视方向；重复小窗可概括成同方向节奏，不捏造新楼层或替换建筑。
- **饱和度与光照**：按模块一选定的色彩模式执行；已有色彩的夜景保留低明度及原有发光区，阴天保持灰调，夕阳只在原有暖色区域表达。黑白风景补色时保留明暗层次，颜色是艺术选择；不套用人像示例的发色/肤色组合。

### 检查清单

- [ ] 地平线、空间深度、道路/水岸走向和建筑几何可对应源图。
- [ ] 疏密与对比体现原有远近关系，没有把所有区域画成同等清晰。
- [ ] 树叶、云、水、砖石已蜡笔化概括；天空、地面与建筑仍是不同空间区域。

## 四、动物与静物表现规范

- **动物**：保留物种、耳形、口鼻轮廓、躯干比例、可见肢体、尾巴、花纹及眼睛朝向；短毛用顺体积短线，长毛/羽毛用少量成束笔触。不可添加人类腮红、眉毛、手势或服饰。
- **植物**：保留主干分叉、叶团外形、花形、花盆及疏密关系；次要叶片可合并成色块，主要花朵/果实的位置和数量不能随意增加。
- **静物**：保留器物外形、开口、把手、接触点、堆叠和投影。圆口椭圆遵循原透视，不因稚拙画风改变物品结构。
- **材质概括**：毛发/羽毛/枝叶采用随形排线；玻璃保留透明关系与边缘反射；金属以强明暗色块和短亮线提示；陶瓷用较宽平涂与少量柔和亮部。不把所有材质画成同样的毛绒表面。
- **高光尺度**：一个独立物体通常保留 1–3 组主要高光形状，按原图位置概括；这不是补画配额，原图无高光时不添加。高光与排线不能吞掉关键轮廓、标签或图案。
- 有文字或标识时保留所在区域、朝向和布局，不编造新字；文字准确性是用户重点时须单独核对，发现乱码不能声称完全还原。

### 检查清单

- [ ] 物种、肢体、花叶、器物比例及摆放关系保持，主体没有被拟人化。
- [ ] 毛发、羽毛或高光已概括为蜡笔色块/排线，仍有材质区别。
- [ ] 关键花纹、标识与轮廓可辨，没有新增表情或装饰。

## 五、背景与色调锁定规范

- 生成前在提示词中记录主要区域及其位置、源色和明暗。例如“上部为淡灰蓝天空，中部为深绿树丛，下部为暖灰路面”；实际记录来自输入图，不复制示例配色。黑白线稿先记录原有明暗分组，再另外列出获准的局部配色计划，不把补色误写成原图已存在的颜色。
- **纯色/简单背景**：沿用该颜色。白底保持中性白，可有细微白纸齿纹与低对比起伏；不能出现明显黄/绿底、暗角或全图晕影。用户指定纯色 #FFFFFF 时不加背景纹理；原图有的主体接触阴影按原位置保留。透明底默认保持透明；工具无法保留时说明限制，不擅自换成有色底。
- **复杂环境**：按前中远景分别锁定区域形状、相对面积、冷暖和明暗；光源方向、主投影与反射不能因色块概括而反转。非均匀背景不得强行简化成纯色。
- **抗默认配色偏差**：禁止新增 sage green、暗褐色、杂色或黄纸罩染；源图已有这些颜色则保留。对比的对象始终是源图，不是某种固定审美色板。
- **分开评价主体与纸色**：参考允许的浅金发色或暖肤色不是背景偏色，不能整图去暖把允许的主体颜色一起删掉。锁定的是背景色调与环境层次；主体按已选色彩模式执行。
- **修正提示词结构**：指出原图实际背景/环境、生成图偏差、要恢复的颜色与区域，再重申保持主体、构图和粗糙笔触。修正使用原始源图，不只用已经偏色的结果图。
- **停止边界**：初次生成成功后，仅允许一次视觉修正；修正后再次读取自检。工具失败、结果不可读或修正后仍错时，按主文件兜底，不继续换工具/改词反复生成。

### 检查清单

- [ ] 简单底色/透明状态正确；白底没有被纸张肌理整体染色。
- [ ] 复杂环境结构、色区位置、冷暖和光影关系仍对应原图。
- [ ] 未新增默认配色，原有绿色等颜色也没有被误删。
- [ ] 已允许的主体补色没有被当作背景错误删去；严格黑白请求则没有残留彩色。
- [ ] 已实际读取生成图；有偏差时完成至多一次修正与复查，未通过的版本不作为合格最终图。
